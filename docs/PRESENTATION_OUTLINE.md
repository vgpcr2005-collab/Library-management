# Project Presentation Outline

1. **Opening** — Alliance University Smart Library Management System.
2. **Problem and goals** — circulation, discoverability, and reliable availability.
3. **Protected workflows** — staff sign-in, library dashboard, collection management, circulation, and reports.
4. **Architecture** — JSP/Java Servlet → service/model → JDBC DAO → embedded H2 file database.
5. **Database and transaction design** — normalized entities, stock locking, atomic issue/return.
6. **Live demonstration** — open the local dashboard, search, issue, return, and view reports.
7. **Security and scope** — role-based staff access, password hashing, CSRF, session protection, and production HTTPS.
8. **Java concepts** — show the five concepts using the Concepts page and source mappings.
9. **Testing and responsive interface** — automated model/utility tests and desktop/mobile pages.
10. **Summary and future work** — Azure deployment, university SSO, and possible integrations.
